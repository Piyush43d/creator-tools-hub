# CreatorToolsHub

A responsive, client-side creator tools website for YouTube and Shorts creators.

## Included tools

- YouTube Title Generator
- Description Generator
- Hashtag Generator
- YouTube Tag Generator
- Shorts Hook Generator
- Thumbnail Text Generator
- Short Story Idea Generator
- Caption Generator

## Run locally

Simply open `index.html` in a browser.

Or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

1. Create a GitHub repository named `creator-tools-hub`.
2. Upload `index.html`, `README.md`, `LICENSE`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
